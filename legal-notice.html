About the DataCite Metadata Generator

This is a lightweight, browser-based application for creating, editing, importing, exporting, and validating metadata compliant with the DataCite Metadata Schema. The DataCite Metadata Generator supports XML, JSON and YAML formats, enabling seamless integration with research data repositories and citation workflows.

Purpose

This tool helps researchers, librarians, and data managers generate accurate and standardized metadata for research output, ensuring proper citation, discoverability, and interoperability.

Key Features

  • Create Metadata: Guided forms for entering metadata fields.
  • Import & Export: Import existing metadata or export for repository submission.
  • Format Support: XML, JSON and YAML compatibility.
  • Validation: Automatic checking against the DataCite Metadata Schema.
  • Browser-Based: No installation required.

Use Cases

  • Preparing metadata for repository submissions.
  • Editing existing metadata records.
  • Validating metadata before dataset publication.

Disclaimer

While every effort is made to ensure compliance with the DataCite Metadata Schema, users remain responsible for reviewing and verifying metadata prior to submission.

About this project

The DataCite Metadata Generator was developed by LMU Center for Digital Humanities and University Library of LMU Munich. It is part of the project Aufbau HITS FDM (Digitalverbund Bayern).

This tool was developed with funding from PID Network Deutschland as part of the implementation phase of the practical guidelines for DataCite DOI metadata providers, funded by the German Research Foundation (DFG, project number 506475377).
